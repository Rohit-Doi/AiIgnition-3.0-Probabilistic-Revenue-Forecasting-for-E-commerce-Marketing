# Submission checklist

## Submission guide (scored pipeline)

- [x] `run.sh` at the repo root, executable, also runs as `bash run.sh`
- [x] Accepts `DATA_DIR`, `MODEL_PATH`, `OUTPUT_PATH` with defaults; one command, no prompts
- [x] Feature generation and prediction only; no training, no network, no LLM
- [x] Reads whatever CSVs are in `DATA_DIR` (recognised by header, then by name; any row count)
- [x] Fails loudly: `set -euo pipefail`, the previous output file is removed first, missing values abort the write
- [x] `pickle/model.pkl` committed (about 1 MB, plain dict + LightGBM model text; no library classes pickled)
- [x] `requirements.txt` fully pinned; installs on Python 3.10 – 3.13
- [x] Output written fresh to `OUTPUT_PATH` in the announced column format
- [x] Seeds fixed; no absolute paths
- [x] Verified in fresh virtual environments (see README, "Verified environments")
- [ ] Repo pushed to GitHub and set to public
- [ ] Repo URL, run command, team and college sent to the organisers

## Robustness checks performed on `run.sh`

| Input | Result |
